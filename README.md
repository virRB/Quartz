# Quartz

## What is this?
- Quartz is a minimalistic estoeric language, desgined around symbolic instructions and memory management

## How to start?
- First, download the QuartzInstaller provided
- Then, from that folder, without taking it out from the folder, run `installer.py`
- After that, restart your terminal, and you should be able to use **qz**
- To create a project, run
```bash
qz build <projectname>
```
 in terminal
 - Then select this project as the directory, most commonly done via
```bash
cd <projectname>
```
- Then, you can open this in file explorer, and edit the file in notepad or vscode or any text editor of your choice
- Then, in terminal, in that project directory, to run the project you can do
```bash
qz run
```
- Some other commands include `qz help` which displays all commands and their use, and `qz version` which displays your current installed version of Quartz
- If you are a Visual Studio Code user, you can download the Quartz v1.0 extension from the extension store
- The logo should be a Q and a Z
